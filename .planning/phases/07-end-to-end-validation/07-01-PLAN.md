    **Part A — Credential guard (module-level, fails at import time):**
    ```python
    import os
    _USERNAME = os.environ.get("VW_TEST_USERNAME")
    _PASSWORD = os.environ.get("VW_TEST_PASSWORD")
    if not _USERNAME or not _PASSWORD:
        raise EnvironmentError(
            "E2E tests require real VW credentials.\n"
            "Set VW_TEST_USERNAME and VW_TEST_PASSWORD to run live tests.\n"
            "  export VW_TEST_USERNAME='your-email@example.com'\n"
            "  export VW_TEST_PASSWORD='your-password'"
        )
    ```
    This raises EnvironmentError at pytest collection time — never silently skips.

    **Part B — Log file setup:**
    Configure a `logging.FileHandler` writing to `tests/e2e/e2e_run.log`. Set log level to DEBUG so token values (truncated) and all assertion results are captured. Use a pytest session-scoped autouse fixture `_setup_logging` to install the handler.

    Token truncation helper:
    ```python
    def _truncate_token(t: str) -> str:
        return t[:12] + "..." if t and len(t) > 15 else "(empty)"
    ```
    Export `_truncate_token` for use in test files.

    **Part C — Module-scoped login fixture:**
    ```python
    import pytest
    import pytest_asyncio
    from aiohttp import ClientSession
    from aiohttp import CookieJar
    from volkswagencarnet.vw_connection import Connection

    @pytest_asyncio.fixture(scope="module", loop_scope="module")
    async def na_connection():
        jar = CookieJar()
        async with ClientSession(cookie_jar=jar) as session:
            conn = Connection(session, _USERNAME, _PASSWORD, country="US")
            result = await conn.doLogin()
            if not result:
                raise AssertionError(
                    f"NA doLogin() returned False.\n"
                    f"Username: {_USERNAME!r}\n"
                    f"Check credentials and VW API availability."
                )
            assert conn.logged_in, "conn.logged_in is False after successful doLogin()"
            yield conn
    ```

    The fixture uses `scope="module"` with `loop_scope="module"` (required by pytest-asyncio strict mode for module-scoped async fixtures). This ensures a single real login per test module, not per test.

    Full imports needed: `os`, `logging`, `asyncio`, `pytest`, `pytest_asyncio`, `aiohttp.ClientSession`, `aiohttp.CookieJar`, `volkswagencarnet.vw_connection.Connection`.
  </action>
